# Wae Watu — Reef Resort & Sanctuary

> *Days measured in tides, not hours.*

A luxury eco-resort experience landing page for **Wae Watu Reef Resort** by **Terra Ecosystem**.

## Features
- **Hero Background Slideshow**: Aerial overwater cottage sea views with smooth crossfade and navigation controls.
- **Section 2 Carousel**: 9-card swipeable experience carousel showcasing activity highlights.
- **Dining Section**: Gourmet luxury dining menus & oceanfront restaurant venues.
- **Reef Conservation Section**: Coral restoration metrics & underwater marine life showcase.
- **Interactive Booking Modal**: 3-step reservation flow with WhatsApp confirmation screen.
- **Terra Ecosystem Branding**: Integrated transparent emblem logo.
